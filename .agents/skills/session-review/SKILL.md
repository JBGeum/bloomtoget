이번 대화 전체를 돌아보고 복습 노트를 작성한다.

## 저장 위치

사용자 전역 AGENTS.md에 지정된 학습 자료 저장소 아래 `bloomtoget/sessions/YYYY-MM-DD.md`(오늘 날짜)에 저장한다. 경로를 찾을 수 없으면 사용자에게 묻는다. 저장소 안에는 쓰지 않는다.

같은 날짜 파일이 이미 있으면 맨 아래에 `---`로 구분해 이어 붙인다.

## 개념은 notes/에 모은다

「배운 개념」을 쓰기 전에 같은 학습 자료 저장소의 `notes/README.md` 색인을 읽는다. 분류 폴더를 훑지 않는다. 노트 형식과 분류도 이 파일을 따른다.

- **색인에 있으면** 그 노트를 열어 이번에 새로 안 것을 반영하고 `## 출처`에 오늘 세션 링크를 더한다. 세션 노트에는 개념 본문 대신 노트 링크 한 줄만 남긴다.
- **색인에 없으면** 다시 찾아볼 값어치가 있는 개념만 `notes/<분류>/<개념>.md`로 만들고 색인에 한 줄 추가한다. 새 노트에도 `## 출처`에 오늘 세션 링크를 넣고, 세션 노트에는 노트 링크만 남긴다. 이번 한 번만 쓸 사실은 세션 노트에만 둔다.
- 제목이 달라도 같은 개념이면 기존 노트에 합친다. 색인의 설명과 해당 노트 본문을 읽고 판단한다.
- 이미 있는 노트와 이번에 안 것이 어긋나면 개념 노트를 고친다. 지난 세션 본문과 사용자의 회고는 고치지 않는다. 같은 날짜의 추가 세션도 기존 내용 뒤에만 이어 붙인다.

## 형식

```markdown
# YYYY-MM-DD 세션 노트

## 오늘 한 일
- (사실만. 커밋 해시, PR·이슈 링크)

## 배운 개념
### 세션에만 남길 개념 이름
- 정의: 한 줄
- 이 저장소에서: 이번 대화에서 실제로 마주친 예
- 왜: 그렇게 하는 이유, 다른 방식과의 차이

### 개념 노트로 정리한 개념 이름
- [개념 이름](../../notes/<분류>/<개념>.md) — 새로 작성 또는 갱신

## 결정과 이유
- (무엇을 골랐고 무엇을 버렸는지, 근거)

## 복습 질문
1. 질문
   <details><summary>답</summary>

   답

   </details>

## 다음 할 일
- (하나만)

## 내 회고
```

## 작성 원칙

- 대화에서 실제로 설명하거나 결정한 것만 쓴다. 새 설명을 지어내지 않는다.
- 실제로 다룬 개념과 그에 대한 복습 질문만 작성하며 개수는 강제하지 않는다. 복습 질문은 "왜"를 중심으로 구성한다.
- 복습 질문은 노트로 옮긴 개념의 `## 복습 질문`에도 넣는다. `/review`가 거기서 출제한다.
- "내 회고"는 비워 둔다. 사용자가 직접 쓰는 칸이다.
- 작성 후에는 파일 경로, 섹션별 항목 수, 새로 만들거나 고친 개념 노트 목록만 알려 준다.
